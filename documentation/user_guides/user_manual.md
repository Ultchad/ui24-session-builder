# User Manual

## Overview

UI24 Session Builder creates Soundcraft Ui24R playback sessions.

## Basic Workflow

1. Import audio files.
2. Verify audio metadata.
3. Assign mixer channels.
4. Generate session.
5. Export session.
6. Copy session to USB storage.
7. Load session on Ui24R.

## Supported Formats

- WAV
- FLAC
- AIFF

## Exported Files

The generated session contains:

- FLAC audio tracks
- Ui24R configuration file

## Limitations

Current known Ui24R limit:

- 22 tracks

See release notes for updates.
