# Ui24R Session Format Specification

## Status

Work In Progress

This document contains only verified observations obtained from sessions generated by the official Soundcraft UI Session Maker application.

Assumptions must be clearly marked.

---

# Session Structure

Observed export structure:

```text
Session Name/
├── Track 01.flac
├── Track 02.flac
├── ...
└── .uirecsession
```

No subdirectories are required.

All audio files are stored in the session root directory.

---

# Configuration File

Filename:

```text
.uirecsession
```

File format:

```text
JSON
```

The configuration file is human readable.

---

# Observed Example

```json
{
  "complete": true,
  "ext": ".flac",
  "files": [],
  "lengthSamples": 16320000,
  "lengthSeconds": 340,
  "mapping": [],
  "names": [],
  "sampleRate": 48000
}
```

# Property Definitions

## complete

Type:

```text
boolean
```

Observed value:

```json
true
```

Purpose:

Unknown.

Possible meaning:

Indicates that export has completed successfully.

Status:

Partially verified.

---

## ext

Type:

```text
string
```

Observed value:

```json
".flac"
```

Purpose:

Default extension used by every audio file in the session.

Status:

Verified.

---

## files

Type:

```json
string[]
```

Contains file names without extension.

Example:

```json
[
  "03 - Vocal 1",
  "04 - Vocal 2"
]
```

Status:

Verified.

---

## names

Type:

```json
string[]
```

Contains display names.

Currently appears identical to the files property.

The distinction remains unknown.

Status:

Partially verified.

---

## mapping

Type:

```json
string[]
```

Observed values:

```json
[
  "i.0",
  "i.1",
  "i.2"
]
```

Likely channel assignment information.

Hypothesis:

```text
Track 1 -> Input 1
Track 2 -> Input 2
Track 3 -> Input 3
```

Additional testing required.

Status:

Partially verified.
