How to prepare the USB key for the Ui24R

Format the USB key as FAT32 only for now.

Create a root folder named Multitrack.

Inside that folder, create one subfolder per session using the name you want, then place the contents of the generated ZIP inside that session folder.

USB drive/
└── Multitrack/
    ├── Live Session A/
    │   ├── .uirecsession
    │   └── *.flac
    └── Live Session B/
        ├── .uirecsession
        └── *.flac
