# Contributing

Thank you for your interest in UI24 Session Builder.

## Before Contributing

Please read:

- README.md
- PROJECT_GUIDELINES.md
- ARCHITECTURE.md

## Development Principles

- Documentation first
- Offline first
- Shared business logic
- No duplicated code

## Pull Requests

Every pull request should:

- Include documentation updates when required
- Include tests
- Follow coding standards

## Bug Fixes

Every bug fix should include a regression test.

## Feature Requests

New features should first be discussed in GitHub Issues.

## Source Code Language

All source code must be written in English.

## Comment Language

All comments must be written in English.

## Documentation Language

Development documentation must be written in English.

User documentation may later be translated.
